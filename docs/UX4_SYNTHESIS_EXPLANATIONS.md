# UX4 · 구조별 탐색 상태와 후보 비교

`0.23.0-ux4`는 UX3 위의 Sol 사용성 변경입니다. 탐색의 구조 생성, 평가 순서, 예산, 후보 순위와 물리 평가 도메인은 유지하고 실제 검사 기록을 추가합니다.

## 사용 순서

1. 01 예시 → ② 연결 조건 → ③ 자동 설계 찾기.
2. **구조별 탐색 상태**에서 직선, Mirror 1/2개, TIR Prism 1/2개, Mirror + Prism의 선택 여부와 부품 상한을 확인합니다. 기존 광학계 조정은 실행 시 별도 항목입니다.
3. **탐색 실행** 후에는 실제 초기 경로, 기하 검사/통과, 광학 배치 계획, 조정 횟수와 표시 후보를 확인합니다. 미지원 평가, 평가 도메인 제한, 기하·부품 제한과 탐색 한도를 구분하고 원문 사유 및 다음 확인 항목을 표시합니다.
4. **후보 비교**에서는 같은 구조·평가 도메인·공동 공차 cohort의 대표 후보를 먼저 표시합니다. 다른 후보를 펼쳐 모두 선택할 수 있습니다. Lens/Mirror/Prism 수, 조건부 overlap, OAT/Joint coverage를 확인하고 **선택 후보 적용**으로 적용합니다.
5. 모바일은 탐색 완료 시 후보 또는 진단 영역으로 자동 이동합니다.
6. 조건을 변경하면 이전 실행 결과임을 표시하고 Apply를 차단합니다. 취소 시 중간 후보와 진단을 폐기합니다. 탐색 설정 편집과 Preview는 Project를 바꾸지 않습니다.

## 판정의 의미

- **설정에서 제외**: Family 미선택 또는 해당 Fold조차 만들 수 없는 개수 제한입니다. Prism 2개는 기본 미선택이며 기본 Prism 상한은 1개입니다. 설정을 바꾸면 실행 전 안내가 갱신됩니다.
- 단일 Prism의 90° 안내는 실제 고정 구간 이후의 광축과 Output 광축으로 확인합니다. 전체 Source/Output의 단순 비교로 고정된 전방 광학계를 무시하지 않습니다.
- 경로 seed가 없다는 것은 선언한 생성기·치수 범위의 결과입니다. 전체 기하학적 불가능을 뜻하지 않습니다.
- 미지원/도메인 기록은 개별 검사에서 발생한 기록입니다. 한 구조 전체가 불가능하다고 단정하지 않습니다. 알려지지 않은 오류는 원문과 함께 상세 확인으로 남깁니다.
- 기하 집계는 초기 seed 검사이며 배치 refinement는 조정 횟수에 포함됩니다. 같은 실패 사유의 횟수는 설계 수나 확률이 아닙니다.
- 로컬 fit, 초기 기하 pool 또는 광학 예산 때문에 남은 작업을 구분해 기록합니다. 목표 통과 후보가 있어도 부분 탐색일 수 있습니다.
- 평가된 후보가 최종 최대 8개 목록에서 빠진 경우는 물리 모델 탈락과 다르게 표시합니다. 정렬이나 비교 class 간 우열 규칙을 바꾸지 않습니다.
- 조건부 Mode overlap은 실제 제품 총 결합효율, 전체 Array 효율 또는 Yield가 아닙니다.

## 검증

- 단일 Prism의 광축 조건, 기본 2-Prism 제외와 부품 상한, 실제 Keep-out/개수 제한, 평가 미지원 Prism 참고 후보, 예산 한도, 입력 오류/취소, 후보 그룹 보존을 모델 테스트로 확인합니다.
- UX3 엔진과 현재 엔진을 동일 광축 및 Output 0.5 mm Y 이동의 동일 옵션으로 비교했습니다. 진단 필드 외 전체 결과(평가 횟수, 원문 제외 사유, 순서, 후보 Project/Mode/공차 포함)가 완전히 일치했습니다. 옵션은 optical 2048 / geometry 32 / local fit 256입니다.
- PC/모바일 offline HTML에서 실행 전 설정 안내, 실제 Prism 제외 사유, stale 결과, 후보 펼치기, Preview 비변경, Apply/Undo, 기존 Joint와 2-Prism 분석을 확인합니다.

## 다음 개발

다음 물리 모델 개발은 Astra 범위입니다. Lens–Prism–Lens와 2-Prism의 지원 도메인 및 독립 ray/field 검증을 우선 구체화하고, 채널별 부품·좌표 계약과 1×8 MLA, 비축 구조, SENKO/Teramount 참고 사례로 확장합니다. UX4는 해당 물리 모델의 지원 범위를 넓히지 않습니다.
